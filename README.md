# AutomationTask

Prompt SOUL.md untuk agent AI yang mengerjakan task airdrop:
connect wallet, task social X, join Telegram, dan isi form waitlist.

## Cara pakai
1. Buka [SOUL.md](./SOUL.md) → klik **Raw** → salin seluruh isinya
2. Tempel ke agent Anda sebagai system prompt / file instruksi
3. Agent akan memandu setup sendiri

## ⚠️ Penting
- Pakai **burner wallet baru** dengan saldo minimal, jangan wallet utama, jangan seed phrase.
- Pakai akun X khusus, karena automasi bisa membuat akun dibatasi.
- Tidak ada jaminan airdrop. Gunakan dengan risiko sendiri.
